This matrix compares the twenty-one members of the Session analytics category: tools that turn what your coding agents record (or are recording right now) into live views, searchable history, cost reports, and audits, one that compiles a session into a shareable replay artifact, one that ties each line of code back to the agent session that wrote it, one that audits whether the records behind any of those numbers are countable at all, one that turns that same history into reviewed fixes for the next run, one that gives Codex alone the desktop command-center treatment, two that record and replay whole runs as portable evidence, plus one that borrows the same agent-readable interface for product analytics.
The category now spans six arrangements: the local retrospective archive and report tools (agentsview, ctx, Memex, ax, AgentTrace, ccusage, CodeBurn, Tokscale, and claude-devtools, which goes deepest on a single harness) plus the records auditor (AgentMeasure, which asks whether those records can support a claim before anyone totals them), the live view (agents-observe, Token Monitor, ClawTrace, Claude Code Agent Monitor, CodexMonitor, Coucou, and the real-time half of Agent Analytics), the shareable artifact (claude-replay, the only member whose output is meant to leave your machine), the git-layer provenance recorder (git-ai, whose attribution record lives in the repository as Git Notes and travels with the code), the run-recording and replay evidence tools (NovaFabric, which wraps any command into a portable Run Capsule to replay, diff, and seal, and Agent-Causality, which records runs as causal event graphs and replays decisions with changed inputs), and the edge case, Agent Analytics, which measures your product's users rather than your agents.

**The category's founding question, retrospective archive versus live observation, now has both answers several times over: agentsview indexes what every agent already did and cost across 60-plus formats, ctx answers where did this line of code come from, AgentTrace answers what did this run cost and why was it slow, ccusage prints what every agent cost by day, week, month, and session, CodeBurn cuts the same dollars by task and branch and proposes what to stop paying for, agents-observe answers what is my agent doing right now (Claude Code and Codex only), ClawTrace answers the same question for OpenClaw by uploading the run, Memex answers where did I already do this and drops you back into the session, Tokscale reads about 50 local stores into one token ledger, Token Monitor watches 47-plus tools live in one widget, claude-devtools reconstructs a single Claude Code session down to which category of context ate each turn, Claude Code Agent Monitor watches Claude Code, Cursor, and Codex in one local control room and can launch, steer, and resume the agents it watches, Coucou renders every waiting approval in a notch or on a locked iPhone or a linked Android phone and is the only member whose answer surface is a character in your screen's top edge, git-ai answers which agent, model, and prompt wrote this line, in git notes that ride every push and survive every rebase, AgentMeasure asks the prior question of the same session records, whether they are countable at all or rest on duplicates and lost forks, ax re-opens the archive as input, turning repeated friction into ranked fixes with verdicts at session-count windows, CodexMonitor gives Codex alone a desktop command center that streams the app-server and meters the account, NovaFabric wraps any command's run into a portable, secret-scanned capsule that replays five ways, diffs run against run, and seals into evidence an auditor can verify without the tool, Agent-Causality records OpenCode and LangGraph runs as causal event graphs whose declared parents slice a failure to the events it depends on, and Agent Analytics answers a different question entirely, how are my product's users behaving, with the same agent-readable stance.**

## Reading the matrix

**The live-observation row is the row this matrix existed to name, and it now has six coding-agent answers**: agents-observe streams hook events into its dashboard while the agents run, Claude Code Agent Monitor streams hooks plus Cursor live events and can also launch and resume agents from its dashboard, Coucou routes the same hook events into a notch island and onto the Lock Screen and is the only one that delivers the approval decision itself, ClawTrace fills the same row for OpenClaw by uploading the run, Token Monitor renders 47-plus tools' usage and limits in one always-on widget as turns happen, and CodexMonitor renders Codex's own app-server stream, approval cards, and thread state in a desktop command center, though it has been dormant since March 2026; Agent Analytics offers a real-time terminal dashboard for its own product events, though the hook-and-stream coding-agent cells still cover only Claude Code, Codex, Cursor, OpenClaw, and Coucou's eleven, so the remaining empty cells belong to the harnesses none of them hook.
The second row worth reading is provenance, which gained a second answer this pass: ctx blames from the session side, mapping a line, file, commit, or PR back to the transcript that produced it, while git-ai records authorship inside git as the agents work, so the answer sits in refs/notes/ai, syncs with the code, and outlives the transcript retention window that bounds every other member; agentsview still deliberately leaves both to cost and history questions.

**Token cost reporting is the row that pays for the tool**: harness-native cost views reset and see only their own sessions, while a pre-indexed store answers multi-tool, multi-month questions in seconds.
An earlier version of the agentsview docs benchmarked its reports at 84 to 223 times faster than ad-hoc parsing (calling that an upper bound); the current docs have dropped that benchmark entirely, so the row should be read as "fast because pre-indexed", with no vendor number left to lean on.
The docs' token-usage page documents schema version 6 again as of 2026-10-26 (it documented version 5 from 2026-10-21 through 2026-10-25), the seventh flip this section has recorded, so scripts consuming those reports should expect churn either way.
AgentTrace adds a cost cell the archive tools do not, with explicit estimate labeling and pricing overrides, while ClawTrace adds per-step cost inside a hosted trace, which is more granular than anything local but only for OpenClaw.
ccusage and CodeBurn make cost the whole product: ccusage is the zero-install incumbent the other tools benchmark against, CodeBurn adds task and branch cuts plus an optimize loop that proposes config fixes, and both print estimates computed from pricing catalogs rather than bills.
Tokscale and Token Monitor extend the same estimate approach to about 50 and 47-plus sources respectively, Tokscale on LiteLLM's catalog and Token Monitor adding currency choice and manual subscription cost records.
AgentMeasure sits apart from the row on purpose: its September 2026 audit of about 110 usage tools ended in merged double-count fixes in the CodeBurn, Tokscale, and Token Monitor columns, so every estimate cell above now carries an externally probed error history, not just each tool's own caveat.
AgentMeasure itself went entirely free on 2026-10-21, retiring its $10 and $20 paid diagnostics in favor of free human-run measurement runs.
On 2026-10-30 the project renamed itself Verovo (v0.9.0, "same measure, new name") and repositioned its center of gravity on buyer-side verification of AI service charges and delivery, with the coding-agent record checks that earned it this column demoted to a Developer diagnostics lane, so read its column as the survivor of a pivot in progress.

**Memex adds the closing move the other archive tools lack: resume-in-place, where finding a session and re-entering it are one action in the TUI, plus the category's only semantic search (BM25 by default, opt-in embeddings that run locally or, since 2026-10-03, against an OpenAI-compatible API that receives your transcript text, so the headline requires setup either way).**
Its 19-engine support table is graded per capability and unevenly at that (some engines have no resume at all, token counting is missing for at least one), and its launch footprint is as thin as ctx's was, so read the column as promising and unproven.

**The 2026-09-27 columns split the category's remaining questions**: AgentTrace is the local cost, latency, and failure auditor that adds slow-run diagnosis the archive tools skip, ClawTrace is the hosted answer that trades privacy for full LLM payloads and an AI analyst, and Agent Analytics tests where the category's boundary sits by serving product analytics to agents instead of session data.

**The 2026-10-28 columns add run-recording and replay as the category's newest arrangement, both from the same observability list and both nearly unadopted**: NovaFabric wraps any command, Claude Code and Cursor included, through a loader or proxy into a portable Run Capsule that replays in five named modes, diffs against another run as a CI gate, and seals into an Evidence Bundle verifiable with standard tools and no NovaFabric install, while Agent-Causality records OpenCode and LangGraph runs as SQLite causal event graphs with declared capture-time parents and slices a failing event to the recorded events it depends on, with counterfactual replay of registered decisions; its own benchmark concedes a 0.3 cause recall and 0.0 joint ancestry on live traces, so the slice is structural, not causal in the strong sense.
The two hold the thinnest adoption figures in the category (734 trailing-month and 154 weekly PyPI downloads, against 6 and 7 stars), so read both columns as promising and unproven.

**The 2026-10-06 columns push on three remaining fronts**: Tokscale widens the ledger to about 50 declared sources and adds the category's first opt-in public leaderboard, Token Monitor makes the widget live and multi-device and keeps history after harnesses prune their transcripts, and claude-devtools shows how deep one harness's logs go when the terminal stops telling you, per-turn token attribution across seven context categories included.

**claude-replay adds the output format the rest of the category never produces**: a single dependency-free HTML file you can email, host, or embed, compiled from seven harnesses' transcripts with secret redaction applied, which makes it the only member whose reader is someone who never installed the tool, and its ledger cells (cost, search, provenance) are empty by design rather than by gap.

**Breadth of coverage is agentsview's moat**: roughly 60 supported sources against Tokscale's about 50, Token Monitor's 47-plus, CodeBurn's claimed 42, ctx's 40, ccusage's 18, Memex's 19, AgentTrace's 13, AgentMeasure's two harnesses, git-ai's 14 named agents, Coucou's eleven named agents, ax's six, claude-devtools' single harness, the two harnesses agents-observe covers, the three Claude Code Agent Monitor watches, the one each that ClawTrace hooks and CodexMonitor drives, Agent-Causality's two adapters, or NovaFabric's any-command capture, which matters because most practitioners now run two or three harnesses at once.
Agent Analytics is agent-agnostic by design, since any agent that can call HTTP is a client.
ctx's moat is different: agent-facing retrieval, where the consumer of the search is your next session rather than you.

## Choosing from the matrix

- Running three or more different coding agents and wanting one private history and cost view: agentsview.
- Wanting your agents to recall why code exists, from the session that wrote it: ctx, with its self-reported numbers accepted.
- Wanting to know which agent, model, and prompt wrote a line of code, with the answer stored in the repo itself: git-ai, accepting that only agents following its checkpoint standard are attributed.
- Living in the terminal and wanting semantic recall plus one action back into the session: Memex, accepting a few hundred stars and thin verification.
- Wanting your history to fix your next run, with recall, branch costs, skill scores, and model routing in one local graph: ax, accepting a 121-star, AGPL-licensed, solo-maintained 0.x.
- Auditing what a run cost and why it was slow, locally and with CI gates: AgentTrace.
- Needing to prove, replay, and diff what a run did weeks later, offline, or to gate agent behavior change in CI: NovaFabric, accepting seven stars and an evidence format that is not yet frozen.
- Debugging a branching LangGraph or OpenCode failure from capture-time causal facts: Agent-Causality, accepting a 6-star AGPL tool whose own benchmark caps what its slices can claim.
- Needing a usage or billing number to survive a dispute before leaning on it: AgentMeasure, which audits the records and marks what cannot be proven rather than printing an estimate.
- Wanting the quickest terminal answer to what did my agents cost this week, without installing anything: ccusage.
- Wanting spend cut by task and branch, plan-quota tracking, and a guard that stops a runaway session: CodeBurn.
- Wanting the widest declared token ledger, and maybe a public profile of your usage: Tokscale, after reading its submit flow first.
- Wanting one live desktop view of tokens and limits across every tool, synced across your machines: Token Monitor, accepting a fast churn rate.
- Wanting to know why a Claude Code context window filled and exactly what a tool call did: claude-devtools.
- Wanting one live control room over Claude Code, Cursor, and Codex that also imports their history and can launch or resume agents: Claude Code Agent Monitor, accepting a single-maintainer, many-featured surface.
- Running Codex and wanting one desktop command center over its threads, approvals, and account usage: CodexMonitor, accepting seven months without a commit while the vendor's own app absorbed the job.
- Wanting approvals to follow you away from the desk, to the notch, a locked iPhone, or (with the Windows and Linux apps) a linked Android phone: Coucou, accepting a weeks-old 0.x app with no independent review yet.
- Running OpenClaw and wanting full-payload traces plus an AI analyst, hosted: ClawTrace, accepting that the traces leave your machine.
- Instrumenting a product your agents are building and reading its traffic through an agent: Agent Analytics.
- Needing to show a session to someone who has no tooling installed: claude-replay, compiling the transcript into one HTML file they can open anywhere.
- Needing to see what an agent is doing right now: agents-observe for Claude Code or Codex, Claude Code Agent Monitor to add Cursor and to drive agents from the same view, or ClawTrace if you run OpenClaw and can upload the run; otherwise a harness-native view is still the fallback.
- Single-agent users: your harness's built-in usage views are probably enough.
