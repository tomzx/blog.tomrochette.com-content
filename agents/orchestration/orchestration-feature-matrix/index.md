**Parallelism is already the free commodity in this category: the only things anyone pays for are review ergonomics and remote execution, and I expect more of these sixty-one to die or pivot before any of them becomes durable infrastructure.**

## Reading the matrix

**The platform rows tell you who these tools are for: Mac-first GUI shops and unix terminal people, with Emdash the only GUI covering all three desktop OSes and the tmux pair unable to follow anyone to Windows.**
cmux and Conductor are macOS only, and Crystal was macOS first with Linux later.
Vibe Kanban's web UI goes anywhere Node goes, which is the one structural advantage of the board design.

**Worktree isolation is the entry ticket, not the differentiator: every session-oriented tool here except cmux, Foremerge, and The Perfect Orchestrator gives each task its own worktree and branch, so the real spread is harness breadth, from LoopTroop's one and Crystal's two to Emdash's 25+.**
cmux's "?" is structural rather than a gap: it is a terminal built for attention routing, not a session manager, and its note records no worktree feature.
Foremerge's tilde is the opposite of a gap: it assumes the worktrees you already run and coordinates plans across them, the one column whose unit of work is the intent rather than the task.
The wrapping pattern dominates (Emdash auto-detects installed CLIs, Claude Squad launches anything through profiles, dmux lists eleven), which means new harness features arrive without waiting for the orchestrator to reimplement them.

**Where your code lives is the quiet differentiator, and Emdash is alone in treating it as a design decision with SSH-first execution and credentials in the OS keychain.**
Cloud execution exists only where a subscription or usage bill is attached, cmux Pro, Conductor Cloud, Omnara Cloud, and JetBrains-managed cloud tasks; dmux is explicitly local-only, Claude Squad ships no hosting at all, and Vibe Kanban's remote services were removed thirty days after its shutdown announcement.

**The status row is the most instructive one in the matrix: of sixty-one tools, one is deprecated, one lost its vendor, one archived itself and named coding agents as the killer, one is a cluster-scale platform entrant, one new column attacks the failure worktrees cannot see, and the counterexamples run on venture rounds and a very loud founder.**
Crystal was deprecated in February 2026 in favor of Nimbalyst, the clearest signal yet that a pure worktree-session manager can be a feature rather than a product.
Bloop shut down in April 2026 and Vibe Kanban is orphaned, local workspaces intact, ten commits on the default branch since the shutdown (the first a 2026-09-15 version bump by a former Bloop maintainer, nine more with substantive fixes through 2026-09-19), a v0.1.45 prerelease published on GitHub on 2026-09-19 and no longer listed there as of 2026-09-30 (the tag remains) with npm still serving 0.1.44 as latest, and nobody paid to fix bugs.
Conductor staying a pure session manager and raising money is what keeps the feature-versus-product question contested instead of settled.
**The three 2026 columns sharpen the funding split: Superset raised $11M, Paseo is a solo maintainer with a planned business, and Worktrunk is a single author with no company at all, which is the whole sustainability spectrum in one row.**
**Omnara is the tenth column and the only one that wants to own execution and state:** agents become YAML configs in your repo, machine pools separate where code runs from who can invoke it, and supervision reaches you from a dashboard, phone, CLI, REST API, or Slack, the open-source counterpoint to Claude Managed Agents.
**Happy Coder is the purest thin client in the table:** two harnesses, no worktrees, no hosting, yet 24.0k stars, second only to cmux among maintained tools, because phone access to the sessions you already run is what people actually install.
**JetBrains Air is the vendor entry, and it is the only column whose price model is a bundle:** no standalone fee, four agent families unlocked by a JetBrains AI Pro or Ultimate subscription, with the deepest isolation menu in the table (worktree, Docker, or cloud per task) and org governance behind it, which makes it the strongest evidence yet that this layer is a feature incumbents will attach to existing subscriptions.
**AX is the scale outlier at the front of the table:** Google's Kubernetes-based fleet orchestrator treats agents as a datacenter workload class with sandboxing, network fencing, and checkpoint-resume, which makes every other column here look like what it is, a desktop tool.
**Foremerge is the newest column and the only one that coordinates plans instead of hosting sessions:** agents publish intents with semantic scopes before they edit, and a deterministic detector flags destructive-versus-additive collisions that git merges cleanly, which names the residue every worktree column here leaves behind.
**OpenRig makes the topology itself the artifact: a YAML rig declares pods, seats, edges, and a culture, and the daemon boots ordinary Claude Code and Codex sessions into named seats it can snapshot and restore by name.**
Where the other control planes here own execution, a board, or a fleet, OpenRig owns the team's identity and its restart, and it is the one column whose coordination runs over the terminal itself rather than a second message bus.

**The trio this run added, Agent Orchestrator, 1Code, and Bernstein, is a leadership proof, a tombstone, and a counter-position.**
Agent Orchestrator (AO) is the evidence that 12.8k stars and daily nightlies can arrive on a 15-point launch thread, under a fourth organization name in eight months, which makes it the volume leader whose identity you cannot yet cite.
1Code is the tombstone: 5.6k stars in two months, silent since March, formally archived by its owner on 2026-07-07, the clearest demonstration yet that the agent-client genre's launch wave is not retention.
Bernstein is the counter-position, the one column that removes the LLM from the coordination loop entirely and sells replayable, auditable runs with policy gates, the strictest answer yet to the category's "who verifies the workers" problem.

**The five columns added on 2026-10-06 are the widest spread the table has taken at once: a hyperscaler testbed, a graph runtime, a DAG-planning host agent, a nine-CLI tmux TUI, and the category's largest star count, which is inherited.**
Scion is the isolation outlier, the only column giving each agent its own container, worktree, and credentials, while Google's README openly calls it an unsupported testbed.
LangGraph is the distribution outlier at 4.55 million npm installs a week, and the only column that is a library you build on rather than a tool you run.
Raven brings the DAG-planning host and the category's most instructive launch record, an HN moderation warning for AI-generated comments alongside self-published benchmarks.
Agent Manager joins the tmux family with the deepest pane-reading integration and the genre's own verdict from its launch thread: dozens of these, barely distinguishable.
Ruflo is the caution: 73.9k stars inherited from the claude-flow rename, download badges that cite the project's own proof JSONs, and a three-point Show HN thread as the only independent footprint.
**Yao is the fifty-third column and the second inherited-stars caution, with a twist: the stars are five years old rather than renamed in.**
The count was accumulated by a 2021 low-code engine whose only HN story is a 2-point launch from 2022, the agent-era product (cross-device workspaces, a task board, first-party DeepSeek Harness and Jev integrations) is months old as a pitch, and the modified Apache-2.0 license adds a commercial-license floor at 50 employees or $1M revenue that none of the pure-MIT columns here carry.

**The six columns added on 2026-10-07 come from the category's own mapped awesome list and divide by what each thinks the unit of work is: a conversation, a task on a board, or a message between terminals.**
AG2 is the fork that kept AutoGen's community line alive while the vendor successor absorbed the upstream, and CAMEL is the 2023 role-playing origin the framework family had been missing, still shipping on PyPI.
PraisonAI is the low-code self-reflection entrant whose 2026 advisory about unenforced sandbox restrictions is the critical source its note leads with, Agent Teams is the AGPL boss-and-team desktop with the deepest review controls in its cohort, hcom is the smallest column and the only one that is pure message fabric over the terminals you already run, and Agentlas OS is the hub that stands up a temporary orchestrator per task, whose installer rewrites your existing host configs and whose README opens with install instructions addressed to AI assistants.

**The four columns added on 2026-10-03 move up the stack from sessions to systems:** Agent Swarm routes chat and issue-tracker intake through a lead agent into Docker-isolated workers that ship pull requests, AgentGrid makes the desktop canvas itself the delegation surface with a master agent arranging workers over MCP, AgentsMesh turns registered machines into AgentPods under a ticket-and-loop console, and Buzz steps outside the editor entirely, making the team's communication fabric, a Nostr event relay you host, the coordination layer.
AgentGrid is the only one with no public repository, and only Agent Swarm and Buzz carry OSI licenses (AgentsMesh is BSL 1.1), so the wave repeats the category's oldest lesson: the coordination idea is cheap to describe and expensive to trust.
**The seven framework columns now split the museum wing from the business park:** AutoGen is in maintenance mode and MetaGPT dormant, AutoGPT and LobeHub run active hosted platforms, and CrewAI, Agno, and Mastra are the funded, actively shipping generation that inherited the abandoned mindshare, which is why I weight the parallel-agent columns as where the daily engineering work is.

**The eleven new columns split into three families, and the split says more than any single feature cell.**
Four are process engines that own a workflow rather than a session: Crewplane sequences a Markdown DAG across CLIs and keeps the run record on disk, Sandcastle exposes the same instinct as a TypeScript library over Docker, Podman, or Vercel sandboxes, LoopTroop wraps OpenCode in council planning and fresh-context recovery, and oh-my-codex adds skills, memory, and worktree teams to Codex CLI.
Three are visual surfaces: GraphCode arranges live sessions into a graph whose hand-off, message, and spawn edges fire on shell predicates, Helmor is a local-first workbench that carries a task through review, test, merge, and one-click PR, and Open Swarm is a mission-control canvas with unified tool approvals and per-session cost tracking.
Four are platforms or boards: Lanes puts parallel PTY sessions on a macOS issue board and pairs it with a self-hostable agent-access endpoint, Orca is the MIT, cross-platform ADE with a mobile companion and 27+ agents, Multica assigns issues to agents as teammates on a self-hostable board, and The Perfect Orchestrator is a one-star tmux harness whose adversarial verification of workers is the most interesting idea of the batch.

**The eight columns added on 2026-09-29 are the framework-and-platform wave the parallel-agent columns keep getting compared to, and they mostly answer a different question.**
CrewAI, Agno, and Mastra orchestrate role-based agents and workflows against your own model bills, Dify and Sim build agentic business apps on a visual canvas, Flowise is the archived proof that the genre's weakest incumbent dies first, Atlas makes the session history itself the product, and Squad wires a team of agents as repo files inside GitHub Copilot CLI.
Only Atlas and Squad even touch a repository, which is why the wave reads as adjacent rather than core: this category's daily work is still worktrees, sessions, and review.

**The new entrants sharpen the category's two fault lines: openness and maintenance.**
Orca, Helmor, Lanes, and Open Swarm stay free or freemium on venture or solo funding, while Multica's 52.0k stars and custom, non-OSI license are exactly the caveated popularity signal this matrix exists to flag.
The Perfect Orchestrator last committed in June 2026, Sandcastle's default branch woke with maintenance commits on 2026-10-02 after three quiet months and still ships no release, GraphCode is barely two months old with one maintainer, and LoopTroop and Crewplane are early with tiny star counts, so the feature-versus-product question the earlier columns raised now has a shorter runway.
**The one new capability claim worth taking seriously is adversarial verification:** The Perfect Orchestrator will not count a finding until a different worker fails to refute it, which is a sharper answer to worker overconfidence than any review surface in the table.

**Review is the bottleneck this category actually sells, and delivery tracks funding: Conductor has the deepest review surface (diffs, checks, PR page, code review), Emdash and Vibe Kanban carry full PR flows, and the terminal tools stop at diff tabs and merge menus.**
Claude Squad's preview tab and dmux's pane-menu PR cover the dispatch, wait, review, merge loop, but nobody should expect checks or inline comments there.
**Gas Town is the exception that proves the row: its Refinery is a Bors-style merge queue with verification gates, review as infrastructure rather than review as a pane.**

**The two 2026-10-07 columns attack the category from its two opposite ends: structure and reach.**
Archon encodes the process itself as committed YAML workflows, one worktree per run, deterministic gates around AI nodes, and triggers from chat platforms, which moves it into Crewplane and Bernstein's workflow-runner seat with more trigger breadth and a heavier Claude Code setup dependency.
T3 Code is the reach outlier: native clients on four surfaces driving six harnesses under the subscriptions you already pay, which takes Happy Coder's thin-client thesis to every screen and every harness at once, with a nightly-grade single company behind it.

## Choosing from the matrix

- Want the deepest GUI review flow on a Mac and accept a closed client: Conductor.
- Want an auditable client, Windows or Linux support, or agents running next to remote code: Emdash.
- Live in the terminal: Claude Squad for the smallest footprint, dmux for multi-agent fan-out and resumable panes.
- On macOS and drowning in sessions that need attention: cmux's notification rings and unread panel.
- Want planning-first and vendor-less: Vibe Kanban, accepting that it is orphaned, with community commits resumed but no stable release since April 2026.
- Want to supervise agents from your phone over an encrypted relay, self-hosted and FOSS: Paseo.
- Want your existing Claude Code or Codex sessions on a phone, end-to-end encrypted, and nothing more: Happy Coder.
- Want a control plane that owns agent execution and state behind one API, on your own hardware: Omnara.
- Want declarative fleet-scale orchestration on Kubernetes instead of a desktop app: AX, accepting pre-stable churn and cluster operations.
- Want a macOS agentic IDE around your existing subscriptions, five or more parallel sessions: Superset, accepting the ELv2 license and beta Linux.
- Already pay for JetBrains AI Pro or Ultimate and want isolation choice plus org governance around four agent families: JetBrains Air, accepting the preview status and credits-only cloud.
- Want the worktree lifecycle automated inside your own shell with no app at all: Worktrunk.
- Run several agents in parallel worktrees on one repo and fear clean merges that break the design: Foremerge, advisory and local-first.
- Want policy-as-code, deterministic scheduling, and offline-verifiable run receipts around parallel agents: Bernstein, accepting beta-grade tooling and no LLM in the planning loop.
- Want a self-hosted control plane that defines a cross-harness Claude Code and Codex team in YAML and restores it by name after a reboot: OpenRig, accepting macOS or Linux, an invasive provider-config setup, and no agent sandboxing.
- Want nine coding CLIs in one tmux TUI with review comments that reach the agent: Agent Manager, accepting no cost tracking and 0.x churn.
- Want a container, worktree, and credentials per agent with a laptop-to-HA path: Scion, accepting Google's explicit non-support.
- Want proven durable-execution primitives and are willing to build the team yourself: LangGraph, which is a library, not a session runner.
- Want a DAG-planned team of built-in and external agents, self-hosted: Raven, accepting the AI-comments launch record and self-published benchmarks.
- Want prebuilt swarms, memory, and federation over Claude Code and Codex: Ruflo, accepting inherited stars and self-measured adoption badges.
- Want agents working across your own desktop, phone, and browser under one self-hosted board: Yao, accepting the modified license, the pre-1.0-of-five-years release line, and stars inherited from its low-code era.
- Want chat and issue-tracker intake turned into pull requests by Docker-isolated workers under a lead agent, self-hosted: Agent Swarm, accepting a high-velocity single-vendor dependency and a Docker-plus-database operational floor.
- Think in spatial layouts and want master/worker delegation you can watch and interrupt on one desktop canvas: AgentGrid, accepting closed source and an early-adopter price that will reset.
