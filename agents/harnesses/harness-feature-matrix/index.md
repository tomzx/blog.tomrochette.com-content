This matrix compares the forty-two harnesses profiled in this section, feature by feature, so the shortlisting step does not require reading forty-two notes.

**No harness has everything, and the two axes that actually decide the purchase are client openness and who pays for tokens: everything else is converging.**

Legend: ✓ supported, ✗ not supported, ~ partial or conditional, ? not verified.
Each column links to the full research note; every cell below traces to a source cited there or in the references.

## Reading the matrix

I read this table by columns rather than rows: pick the two rows you actually care about, then let the rest fall away.
The Company row is context, not a feature axis: it names the maker (or, for goose, the foundation that now stewards the code) and links each site.
**The open-client column splits the field into three groups, and each group answers a different buyer.**
aider, Atomic Agent, AutoDev, Cline, Codex, Exo, fx, Gemini CLI, goose, gptme, Grok Build, Juggler, jcode, Kimi Code, Kilo Code, LongHorizon-Harness, MiMo Code, Mini-SWE-agent, Nanocoder, Oh My Pi, Omnigent, OneCLI, OpenCode, OpenHands, Pi, Qwen Code, Unreal Agent, ZCode, and Zerostack hand you auditable code; Crush is source-available with a competing-use restriction that expires per version, and Ante publishes Apache-2.0 source whose prebuilt binaries answer to separate preview terms; Amp, Bullet, Claude Code, Command Code, Copilot CLI, Junie, and Warp Agent CLI are binaries you trust.
MiMo Code carries an extra `USE_RESTRICTIONS.md` addendum on top of its MIT grant, which its own paragraph below names.

**Subscription versus keys is the second axis, and it is orthogonal to openness.**
Codex is open and subscription-fed, and Copilot CLI rides the same model one platform over, included from GitHub's Free plan up and metered in AI Credits; Amp is closed and, since its September 2026 Free Agent change, free to run on your own compute, subscriptions, or keys with no BYOK token fees outside Enterprise; aider and Crush are keys-only, period; goose reuses the Claude, ChatGPT, or Gemini subscription you already pay for via ACP, and fx reuses ChatGPT and Grok subscriptions via OAuth while its v0.0.11 custom connections let local and OpenAI-compatible endpoints skip its gateway.
Command Code sells its own credit bundles at open-model prices, from $1 a month up.
The six new columns spread across the same axis: Ante and Juggler take subscriptions alongside keys, Warp folds all usage into its own credit meter, OneCLI starts teams at $0 with $5 of credits, Bullet is free with no subscriptions at all, and Zerostack stays keys-only, while Nanocoder reuses ChatGPT Codex, GitHub Copilot, Kimi Code, and Z.ai sign-ins among its roughly 30 documented providers.
The two newest columns split the same way: Mini-SWE-agent is keys-only by design, and Oh My Pi signs in through the OAuth and coding-plan routes of Anthropic, OpenAI Codex, GitHub Copilot, Kimi Code, and the GLM plans.
Atomic Agent joins the subscription side from the opposite direction: it drives your existing Claude Code and OpenAI Codex CLI sign-ins directly, so a flat-rate subscription powers a harness that is not the vendor's.
The three columns this run adds split the same way again: gptme reuses your ChatGPT or SuperGrok plan, AutoDev is keys-only, and LongHorizon-Harness inherits whatever its wrapped backend CLI is signed into.

**Local-model support now cleanly separates the BYOK purists (aider, Ante, Atomic Agent, AutoDev, Cline, Copilot CLI, Crush, goose, gptme, Juggler, jcode, Junie, Kilo Code, MiMo Code, Nanocoder, Oh My Pi, Omnigent, OpenCode, OpenHands, Pi, Qwen Code, Zerostack) from the platform players** whose value-add assumes their own model routing, a group Bullet and Warp Agent CLI now join.

**The feature everyone lacks is a different one, which is the tell that the category is immature in different places:** aider lacks the agent loop, Gemini CLI lacks a consumer future, Crush lacks documented subagents, OpenCode lacks its own cloud execution, and all three 2026 entrants lack cloud execution: Cline and Qwen Code run only where you stand, and goose keeps its IDE story experimental.
**The two newest columns redraw that map again:** Kilo Code bundles subagents, schedules, and cloud tasks into an editor-native open agent, which nothing else in this table does, while OpenHands skips AGENTS.md entirely because its `.openhands` customization replaces repo-instruction files.
**fx, the fourteenth column at the time it joined, redelines the axis itself:** it is the only harness here built to be a dependency instead of an environment, and the only open one whose tokens must cross its sponsor's gateway.
**jcode bets the constraint is hardware, not intelligence:** it is the only entry whose measured RAM floor, native memory graph, and same-repo swarm all assume you will run dozens of agents at once, and the only one that rebuilds its own binary on request.
**DeepSeek Harness is the everything-is-a-plugin bet:** fully open with subagents, skills, and ACP editor support already filled in, and question marks on MCP and AGENTS.md that a developer-preview project earns.
**Pi is the deliberate-omission bet:** a frozen core plus extensions you can read, with the widest subscription reuse in the table and local models through llama.cpp; its v0.99.0 line bent the policy by shipping MCP and codemode as built-in extensions, though subagents and plan mode remain extension territory.
**Ante takes the footprint bet furthest:** the only column whose local inference engine lives inside the binary itself, though its prebuilt releases answer to preview terms the Apache-2.0 repo does not carry.
**Bullet is the latency bet:** free, closed, and the most transparent vendor self-report in the table, with question marks wherever its note cannot see.
**Juggler is the GUI bet:** conversation trees, durable sessions, and inspectable everything from a solo Go author, AGPL app code included.
**OneCLI is the security-team bet:** credentials injected at a gateway so agents never hold real secrets, priced in seats and credits rather than keys.
**Warp Agent CLI is the vendor-unbundle bet:** cloud agents and multi-agent orchestration on a closed binary, everything through Warp's meter.
**Zerostack is the GPL footprint bet:** subagents, worktrees, sandboxing, and hooks in a solo Rust binary, with MCP and other headline features behind compile-time flags.
**Kimi Code is the challenger-vendor bet:** the first column whose maker sells the cheap model it is tuned for, with subagents, hooks, and marketplace skills already filled in and question marks where its docs stay silent.
**Exo is the self-modification bet:** the only column whose harness policy is itself agent-editable, which earns it question marks on the conventional rows and a clone-and-lineage mechanic nobody else has.
**Grok Build is the open-closed bet:** an Apache-2.0 client from a lab that accepts no outside contributions, released at roughly one version per day, with every session crossing its inference proxy by default.
**ZCode is the trust-recovery bet:** a complete workbench released as a flattened two-commit Apache-2.0 dump three days after a wire-level analysis caught it silently uploading whole workspaces, with locked PRs and disabled issues leaving open how real the opening is.
**Unreal Agent is the async bet:** tool calls run as background operations while steering stays live, with no subagents, no workflows, and no MCP by design, the only column whose cost thesis is harness scheduling rather than model choice.
**MiMo Code is the long-horizon memory bet:** the only column whose context strategy is a separate checkpoint-writer subagent rebuilding the window from a four-layer store, paired with a goal-verifying judge and deterministic JavaScript workflows, and the only one carrying a use-restrictions addendum on top of its MIT license.
**Command Code is the taste-learning bet:** a closed client whose differentiator is a personalization model distilling your accepts, rejects, and edits into shareable markdown, priced from a dollar a month on open models, with question marks wherever its docs and its issues-only repository stay silent.
**Copilot CLI is the incumbent-distribution bet:** the default harness of every Copilot seat, first-party to GitHub.com with preview cloud sandboxes and a free tier nobody else at this scale matches, closed like the platform it ships with.
**Omnigent is the meta-harness bet:** it does not carry a model into your repository at all, it wraps the harnesses already in this table (Claude Code, Codex, Cursor, OpenCode, Pi) behind one uniform API with policies, sandboxes, and shared sessions, which makes its feature cells descriptions of the wrapper while the wrapped columns answer for the model.
**Nanocoder is the governance bet:** a sponsor-funded community collective rather than a company or a foundation, with the widest documented local-engine list in the table and a skills-plus-hooks surface that mirrors the commercial harnesses, against an adoption record (2.5k stars, near-zero discussion) that leaves its ownership thesis untested and a license paper trail (MIT on npm, no LICENSE file in the repository) that embedders must check themselves.
**Mini-SWE-agent is the baseline bet:** the SWE-bench team's shell loop with no subagents, MCP, rules files, or IDE surface by design, which makes it the reference point the other columns are measured against rather than a daily driver, backed by 11.6 million PyPI downloads a month of mostly batch-evaluation traffic.
**Oh My Pi is the fork bet:** Pi's frozen-core philosophy inverted, with LSP and a real debugger wired into the agent loop, eight rules formats inherited natively, and a star count (35.5k as of 2026-10-15) that has passed its parent, paid for with a permanently diverging codebase and the subscription terms-of-service question its launch thread raised.
**Atomic Agent is the small-model bet:** the only column that maintains its own llama.cpp fork (TurboQuant quantization and speculative decoding) and engineers the loop around what small models survive, grammar-constrained tool calls, a cache-stable prompt prefix, a bounded tail, and externalized state, with Fusion as its subagent story and a vendor-run GAIA benchmark whose artifacts are published but unreplicated.
**gptme is the seniority bet:** the oldest codebase in the table (first commit March 2023, eleven days before aider), the only column whose largest contributor is its own autonomous agent, and the one whose persistent-agent layer (git-as-brain workspaces, cross-harness memory in Claude Code's format) treats the harness as a long-lived coworker rather than a session, against the thinnest independent-discussion record of any four-year-old member.
**AutoDev is the one-codebase bet:** a Kotlin Multiplatform agent engine compiled to IDEA, VS Code, CLI, web, desktop, and mobile targets, with five top-level agents and nine subagents, still alpha-only at Xiuper 3.0, carried by a maintainer who wrote about 98 percent of the code, and searchable under a name Microsoft's research framework owns.
**LongHorizon-Harness is the audited-loop bet:** it wraps four columns of this very table as interchangeable executor backends around a manage-execute-audit loop whose read-only auditor is the only writer of task state, with self-run benchmark gains whose own paper discloses the unmatched-privilege caveat, a token bill that swings with the backbone, and eight weeks of commit silence as the open question.

**The out-of-category flags from the 2026-10-12 resolutions both fail the harness test on kind, not quality.** rea.tools (morluto/rea, REA Reverse Engineer Anything, 109,906 stars and a 768-point Hacker News thread as of 2026-10-12, MIT, last push 2026-10-12) gives coding agents a reverse-engineering tool server through one MCP server, a CLI, and an installable skill: binaries, Electron apps, packaged and firmware targets, and runtime behavior, wired to Ghidra, Hopper, and IDA-class engines. It equips harnesses but never carries the model into your repository, so it is rejected here and returned for the skills category (its skill-first distribution) with protocols (its MCP surface) as the alternate fit. langchain-ai/deepagents (30,140 stars as of 2026-10-12, MIT, active) resolves the orchestration flag negative: it calls itself the batteries-included agent harness, but it is a Python and TypeScript agent-building SDK layered on LangGraph's create_agent for general tasks, with no terminal, no BYOK, no AGENTS.md, and no IDE row to answer; its terminal coding derivative dcode is already covered in the retrieval category's LangChain note, and admitting the SDK would preempt the owner-pending single-vendor SDK family question, so the flag closes as not harnesses-kind.

## Choosing from the matrix

- Need an auditable client plus a subscription: Codex or Juggler, with Ante close if you build its Apache-2.0 source.
- Need local models plus MCP: Ante, Atomic Agent, AutoDev, Cline, Copilot CLI, Crush, goose, gptme, Junie, Kilo Code, Oh My Pi, OpenCode, OpenHands, Pi, or Qwen Code.
- Need scheduled autonomous work in the cloud: Amp, Claude Code, Kilo Code, or OpenHands.
- Need editor-embedded agents with deep analysis: Junie or Claude Code.
- Need rules portability across tools: Amp, Ante, AutoDev, Cline, Codex, Crush, fx, goose, Kilo Code, Oh My Pi, OpenCode, and Zerostack read AGENTS.md natively.
- Need an auditable agent platform you can self-host with cloud automation built in: OpenHands.
- Need an agent embedded inside your own tool, sandbox, or pipeline: fx.
- Need dozens of parallel agents on one machine, with memory and coordination built in: jcode.
- Need a graphical workbench where conversations branch and every tool call is inspectable: Juggler.
- Need team agents that never hold real credentials, enforced outside the model: OneCLI.
- Need cloud agents, orchestration, and billing from one vendor subscription: Warp Agent CLI.
- Need a free, latency-first second-opinion agent: Bullet.
- Need the smallest possible RAM floor on small machines or containers: Zerostack.
- Need a big-vendor CLI priced for challenger-model economics: Kimi Code.
- Want a harness the agent itself can rewrite, at your own risk: Exo.
- Need live steering while long tool calls run, inside your own Go service: Unreal Agent.
- Need none of the above, just cheap precise edits on your keys: aider.
- Need an auditable, provider-neutral agent whose runtime is built for very long runs at challenger-model prices: MiMo Code.
- Need to rotate, govern, and share sessions across the harnesses you already run: Omnigent, accepting the alpha badge.
- Need a community-owned agent with local engines as first-class paths and no company behind it: Nanocoder.
- Need a readable baseline harness for research or batch evaluation: Mini-SWE-agent.
- Need IDE-grade LSP diagnostics and debugger control in a terminal agent: Oh My Pi, accepting the fork and the terms-of-service question.
- Need long multi-step work out of small local models, with the harness engineering the context: Atomic Agent, pinning a release and treating the GAIA numbers as unreplicated.
- Need a persistent autonomous agent on your own machine, with memory and lessons that survive between runs: gptme.
- Need one agent platform across JetBrains, VS Code, CLI, and mobile from a single Kotlin codebase: AutoDev, pinning the stable 2.0 line until Xiuper leaves alpha.
- Need hours-long computer-use work that survives context resets and audits its own progress: LongHorizon-Harness, on top of the Claude Code or Codex CLI you already run.
